📖 Methodology

Data Source: 4 CSV datasets — matches.csv (64 matches), stats.csv (832 players), groups.csv (32 group-stage rows), achievements.csv (tournament awards).

Feature Engineering: total_goals = home_score + away_score, goal_difference = home_score - away_score, result (home_win / away_win / draw), goal_involvement = goals + assists, goals_per_match = goals / matches_played.

Outlier Detection: IQR method on total_goals — values outside [Q1 − 1.5×IQR, Q3 + 1.5×IQR] are flagged.

No statistics are fabricated. All displayed values are derived from the actual datasets.
